# MELIKA — Study Planner Web App

این پروژه از فایل HTML اصلی برنامه ملیکا ساخته شده است. رابط و منطق برنامه‌ی فعلی در `index.html` حفظ شده و لایه‌ی ورود، همگام‌سازی ابری، پنل مدیر، یادداشت‌ها و پیام‌رسان به آن افزوده شده است.

## اجرای محلی
برای اجرای PWA بهتر است از یک وب‌سرور محلی استفاده شود، نه بازکردن مستقیم فایل:
```bash
python -m http.server 8080
```
سپس `http://localhost:8080` را باز کن.

## فعال‌سازی نسخه آنلاین
1. یک پروژه Supabase بساز.
2. فایل `database/schema.sql` را کامل در SQL Editor اجرا کن.
3. از Authentication > Users دو کاربر بساز: یک مدیر و یک دانش‌آموز. ثبت‌نام عمومی را فعال نکن.
4. UUID هر دو کاربر را بردار و در SQL Editor پروفایل‌ها را درج کن:
```sql
insert into public.profiles(id,display_name,role) values
('ADMIN_UUID','مدیر','admin'),
('STUDENT_UUID','ملیکا','student');
```
5. در Project Settings > API، Project URL و anon/publishable key را در `config.js` جایگزین کن. هرگز `service_role` را در فایل‌های مرورگر قرار نده.
6. پوشه پروژه را روی یک هاست استاتیک HTTPS مانند Vercel یا Netlify منتشر کن.
7. ابتدا با حساب دانش‌آموز وارد شو. اگر `localStorage` قدیمی روی همان مرورگر موجود باشد، اولین ورود آن را به دیتابیس منتقل می‌کند؛ داده محلی حذف نمی‌شود.
8. سپس با حساب مدیر وارد شو و داشبورد را بررسی کن.

## امکانات افزوده‌شده
- ورود ایمیل/رمز عبور برای مدیر و دانش‌آموز
- نقش‌های admin/student و محدودسازی دسترسی با RLS
- انتقال اولیه داده‌ی `localStorage` با کلید `melika`
- ذخیره ابری وضعیت کامل برنامه و همگام‌سازی تغییرات
- داشبورد شاخص‌های مطالعه و آزمون
- ویرایش برنامه روزانه از پنل مدیر
- پیام‌رسان دوطرفه و realtime
- یادداشت مدیریتی خصوصی یا قابل مشاهده برای دانش‌آموز
- سوابق تغییرات مدیریتی
- PWA و Service Worker

## نکات مهم
- تا پیش از واردکردن مقادیر Supabase در `config.js`، برنامه در حالت محلی اجرا می‌شود؛ قابلیت‌های ابری فعال نیستند.
- حساب‌ها را از پنل Supabase بساز؛ ثبت‌نام عمومی وجود ندارد.
- تغییرات برنامه از پنل مدیر در دیتابیس ذخیره می‌شود و از طریق realtime به دانش‌آموز اطلاع داده می‌شود.
- در نسخه اول، وضعیت برنامه به‌صورت یک JSON مرکزی برای هر دانش‌آموز ذخیره می‌شود تا ساختار قدیمی بدون بازنویسی گسترده حفظ شود.
- فایل `student-original.html` نسخه اصلی دست‌نخورده برای بازگشت و مقایسه است.
